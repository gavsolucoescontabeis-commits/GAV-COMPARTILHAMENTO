# GAV Compartilhar Docs

Portal de documentos de clientes da GAV Soluções Contábeis.

## Estado atual

Protótipo v0.4 em HTML, para testes com dados fictícios. A conexão com Google Drive, autenticação segura e permissões reais ainda não estão implantadas. **Não utilizar com documentos reais de clientes nesta fase.**

## Publicação do protótipo

O arquivo HTML da versão v0.4 deve ser adicionado na raiz deste repositório com o nome `index.html`, preservando seu conteúdo integral. Em seguida, habilitar GitHub Pages em **Settings → Pages → Deploy from a branch → main → /(root)**.

## Estrutura prevista

- Área do cliente: documentos por categoria, competência e ano.
- Área administrativa: cadastro de empresas, conferência de documentos e controle de fechamento de folhas.
- Pastas existentes: TTM, X2026, ADM, RES e FER, sem reorganização física dos arquivos.
- Próxima fase: backend seguro, autorização por CNPJ e integração Google Drive.

Identidade visual: preto, branco e dourado; logotipo oficial GAV.
